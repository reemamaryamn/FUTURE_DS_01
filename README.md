# Superstore Sales Analysis using Power BI Dashboard

## Overview
Sales performance analysis of a US-based retail business (2014–2017) built as part of the Future Interns Data Science & Analytics Track.

## Key Findings:
- Total Revenue: $1.10M | Total Profit: $132.52K
- East region is the top performing market ($330K in sales)
- Technology is the most profitable category
- Canon ImageClass 2200 is the #1 product by revenue

## Tools Used:
- Microsoft Power BI Desktop

## Dataset:
Superstore Sales Dataset - Kaggle
